## 完成判定

目标完成必须同时满足：

- 所有 `R-*` 行状态为“已验证”。
- 每行实现证据指向具体源码文件。
- 每行测试证据指向通过的测试命令和结果。
- 每行文档证据指向手册具体章节。
- 测试报告记录 host、耦合、端口 mock、嵌入式 smoke test 结果。
